# 地铁线路自动规划 Pipeline

## 项目概述

基于OSM数据和人口分布，自动规划地铁线路，目标是最大化平均旅速。

## 技术路线

```
osmnx (OSM数据) → 人口估计 → 1km网格聚类 → 贪心选站 → 直线地铁线路 → 转弯半径平滑 → GeoJSON输出
```

## 版本历史

| 版本 | 状态 | 关键改动 | 问题 |
|------|------|----------|------|
| v1 | ❌ | 基础框架 | 沿道路规划地铁(错误) |
| v2 | ❌ | 加入约束 | 人口分布不均,车站扎堆 |
| v3 | ✅ | 1km网格聚类,直线地铁 | 基本可用 |
| v4 | ✅ | 旅速优化,站距搜索 | 无转弯约束 |
| v5 | ⚠️ | 转弯半径R≥1000m | 平滑算法有问题,需改进 |
| v6 | ⚠️ | 100m聚类,5条线路,转弯约束 | 分线算法有问题 |
| v7 | ✅ | NSGA-II多目标优化 | 覆盖92.6%, 旅速15.2km/h, 里程33.1km |

## v5.1 问题分析

**策略**: 删除R<1000m的违规中间点

**结果**:
- Line1 (北线): 14站 → 6站, 删除8个违规点
- Line2 (南线): 13站 → 7站, 删除6个违规点
- 违规: 0处 ✓

**问题**:
1. **删除太多站**: 原始线路转弯太急,删除后车站数减半
2. **线路分组策略不好**: 按纬度分两组在浦东这种不规则区域会导致很多急转弯
3. **需要更好的线路生成算法**: 用最小生成树或TSP来连接车站,而不是简单分组

## v7 结果

**算法**: NSGA-II 多目标优化 (50代, 5000次评估)

**三个目标**:
1. 最大化旅客覆盖度
2. 最大化平均旅速
3. 最小化地铁总里程

**最优解**:
- 覆盖人口: 459,702 / 496,583 (92.6%)
- 平均旅速: 15.2 km/h
- 总里程: 33.1 km
- 选站数: 45
- 转弯平滑后: 35段

**帕累托前沿**: 50个非支配解
